Tambah Akun

Login pakai akun Instagram (Threads nempel ke IG). Password hanya dipakai sekali saat login — yang disimpan hanya token sesi, terenkripsi. Kunci 2FA juga hanya dipakai sekali saat login ini, tidak disimpan. Proxy (kalau diisi) disimpan terenkripsi dan dipakai buat semua aktivitas akun ini — supaya trafiknya keluar lewat IP proxy, bukan IP server.
Catatan: login pakai password saat ini diblokir Instagram dari server (429). Isi Proxy kalau kamu punya proxy sendiri — login jalan lewat proxy itu. Kalau tetap gagal, pakai login sessionid di bawah.

Login pakai sessionid

Ambil sessionid dari browser kamu sendiri (IP kamu dipercaya Instagram), lalu tempel di sini. Sessionid hanya dipakai sekali — yang disimpan tetap hanya token sesi, terenkripsi.
Langkah: 1) Buka instagram.com di Chrome laptop & login. 2) Tekan F12 → tab Application → Cookies → instagram.com → klik sessionid, salin isinya (panjang, mulai dengan angka). 3) Tempel di bawah.

Daftar Akun Baru (tanpa browser)

Daftarkan akun Instagram baru langsung dari aplikasi ini — tanpa buka browser. Kode OTP dikirim ke nomor HP (SMS) atau email, lalu kamu ketik di bawah. Akun baru langsung masuk Daftar Akun. Password hanya dipakai saat pendaftaran ini, tidak disimpan.
Penting: akun baru jangan langsung dipakai posting/komen otomatis — panaskan dulu manual beberapa hari (buka feed, like, follow) supaya tidak kena flag seperti Lily & Noor.
